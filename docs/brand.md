# IQuila Brand

IQuila uses an `iQ` chicken mark to represent intelligent poultry operations, clear reporting, and reliable daily farm records.

## Colors

- Forest: `#1e4d2b`
- Cream: `#fffaf0`
- Sand: `#f5f1e8`
- Earth: `#7a5518`
- Ink: `#17201a`

## Logo

- Web logo: `apps/web/public/logo.svg`
- Compact mark: `apps/web/public/mark.svg`

The IQuila mark combines the initials with a chicken silhouette and uses teal, amber, red, and ink accents.
